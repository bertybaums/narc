NARC Inspector

NARC puzzles are designed so that neither the grid sequence nor the narrative clue is sufficient on its own — but together they uniquely determine the answer. The experiments below probe different dimensions of this narrative–visual interaction. Masking tests whether models can reconstruct hidden grids. Ordering tests whether narratives help recover temporal structure. Odd-one-out tests whether narratives help models recognize which grids belong together. Stances tests how the same visual pattern responds to different narrative framings. NARC-tiny runs the masking test on puzzles that a program generated from children's stories.

How to read this page. Masking is the documented battery: every active puzzle, all current models, order and keyword ablations; a paper on it is under review (September 2026). Ordering, Odd-one-out and Stances are pilot designs from spring 2026; each states its own scope and dates below. NARC-tiny is a separate set of generated puzzles with the same battery; it is not counted in the Masking tab. Counts are per model. The NARC property is a relation between a puzzle and a model, so a model with more NARC puzzles is not a better or worse model, and this page is not a leaderboard.

Masking experiment: One or more grids in a sequence are hidden. The model attempts to reconstruct the masked grid(s) under three conditions: grids only (no narrative), narrative only (no grids), and both (grids + narrative). A puzzle has the NARC property for a given model when it is solved correctly with both but not with either alone.

N = NARC (solved only with both)   G = Grids sufficient (solvable from grids alone)   L = Narrative sufficient (solvable from narrative alone)   × = Unsolvable (failed on all conditions)

Order sensitivity: each NARC cell is re-tested with the grids in randomized order (same clue).   Strong = fails every shuffle (order is necessary)   Partial = solves some shuffles   Weak = solves every shuffle (order incidental). A plain N means order not yet tested.

Narrative sensitivity: each NARC cell is re-tested with the clue replaced by an alphabetized list of its key terms (same grids).   Narrative = fails every keyword trial (narrative form is necessary)   Partial = solves some keyword trials   Lexical = solves every keyword trial (the terms alone suffice).

Ordering experiment: All grids are shown (unmasked) in a shuffled order. The model must recover the correct chronological sequence. Tested under two conditions: grids only and grids + narrative. Agreement with the true order is measured by Kendall's τ (−1 = reversed, 0 = random, +1 = perfect). Narrative lift = τ with narrative minus τ without.

τ = Kendall's tau correlation    Lift = τ(grids+narrative) − τ(grids only)    Positive lift = narrative helps ordering

Stance experiment: Inspired by Daniel Dennett's three interpretive stances. The same grid sequence is paired with three different narratives: intentional (beliefs, desires, goals — e.g., "Red betrayed the truce"), design (functional rules — e.g., "When blue reaches column 1, red overrides"), and physical (step-by-step cell changes — e.g., "Cell (1,1) changes from 1 to 2"), and moral (evaluative reasons — an agent overrides an expected trajectory for ethical reasons, e.g., a soldier refusing an unlawful order). Each is tested via the standard 3-condition masking protocol.

NARC-tiny is a set of puzzles made by a program, not written by hand. The program read 98,113 stories from TinyStories, a public corpus of short children's stories written by language models (Eldan and Li, 2023). From each story it kept the events that can be drawn on a grid: someone or something appears, leaves, moves, goes up, comes down, is picked up, dropped, lost or handed over, a mood changes, a thing is transformed. A grammar then writes that chain of events twice, once as grids and once as plain sentences.

The grids. Each event is the change from one grid to the next. A character is a coloured bar, and its height is its mood: one cell sad, two neutral, three happy. An object is one cell, two if it is big, and grey if it is broken. The bottom row is the ground, and its colour is the place. One grid is hidden. The program hides a grid only where the visible grids leave several one-event completions open (at least three in this sample), the story picks one of them, and every drawing convention the answer needs is shown in another grid.

The two texts. Each puzzle is tested with two clues. The story is the TinyStory as written. The grammar text is the same chain of events written back as plain sentences by the grammar's templates, so it agrees with the grids by construction.

The sample. The program produced 21,864 puzzles. Three models (qwen3.8-27b, gemma-4-31b, gpt-oss-120b) judged whether every extracted event is asserted by its story, and all three passed 11,049 puzzles. The {{ puzzles | length }} puzzles here come from those 11,049: four to seven grids, 8 to 33 puzzles for each of the eleven kinds of hidden event. The sample covers the kinds of hidden event about evenly. The full set does not: in the 11,049, four of five puzzles hide a mood change.
